# Identity Architect

CYTIC BRANDING AGENCY — COMPLETE WEBSITE BUILD PROMPT

Build a premium, modern, highly visual website for CYTIC Branding Agency.

CYTIC is a professional branding agency that helps startups, local businesses, and established companies create outstanding, unique, memorable brands.

The website must feel like a world-class branding studio, not a generic digital agency, freelancer portfolio, template website, or corporate consulting company.

The core brand motto is:

Identity that hits differently.

This motto should become one of the strongest recurring ideas throughout the website.

1. BRAND FOUNDATION

Brand Name

CYTIC Branding Agency

Use CYTIC prominently throughout the interface.

Motto

Identity that hits differently.

Do not replace, paraphrase, or weaken this motto.

Purpose

Turn ideas into distinct brands.

Vision

Create satisfactory, distinct brands for clients.

Mission

Give a feel to every brand made.

Target Audience

CYTIC primarily serves:

Startups

Companies looking to rebrand

Local businesses

Growing businesses

Established companies that need a stronger identity

Value Proposition

Quality distinct brands.

Brand Personality

The website must communicate:

Bold

Professional

Premium

Differentiation

World-class branding.

CYTIC should feel capable of competing with serious international branding studios while remaining approachable to startups and businesses in its market.

Long-Term Ambition

CYTIC wants to become a mainstream branding agency that grows thousands of businesses.

The website should therefore feel scalable and established rather than like a small freelance design portfolio.

3. COLOR SYSTEM

Use CYTIC's official palette:

Primary Navy

#1F2A44

Premium Gold

#C6A75E

Warm Cream

#E8DCC8

Use these colors intentionally.

The navy should be the primary dark brand color.

The cream should provide warmth and breathing room.

The gold should be used as an accent rather than covering the entire website in gold.

Avoid excessive gradients.

Avoid generic startup blue/purple gradients.

Avoid neon colors.

Avoid excessive glassmorphism.

Avoid overly rounded SaaS-style cards.

The visual language should feel editorial, premium, architectural, and intentional.

4. TYPOGRAPHY

Use a modern premium sans-serif typeface.

The typography hierarchy should be dramatic.

Use:

Very large hero headlines

Medium-sized section headings

Small uppercase labels

Clean body text

Tight but readable typography

Strong contrast between headings and supporting copy

Headlines should sometimes occupy multiple lines and become part of the visual composition.

Example:

IDENTITY
THAT HITS
DIFFERENTLY.

Do not make every section text-heavy.

The design should communicate through typography, imagery, spacing, and composition.

5. GENERAL DESIGN PHILOSOPHY

49. FINAL DESIGN TEST

Before considering the website complete, check:

Does it feel premium?

Does it feel minimal?

Does CYTIC have a recognizable visual identity?

Is "Identity that hits differently." memorable?

Is the work more prominent than long descriptions?

Can a client understand the services quickly?

Can a client build an estimated quote without contacting CYTIC first?

Does the quote builder feel professional?

Is App Development clearly included under Digital?

Is Social Media absent from Expression?

Does the website work beautifully on mobile?

Does it feel like a serious branding agency rather than a template?

Is the site visually inspired by high-end branding studios without copying them?

Can CYTIC add more projects and services later?

Can pricing be changed without rebuilding the quote interface?

If any answer is no, refine the implementation before considering the website finished.
